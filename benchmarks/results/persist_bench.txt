SNAPSHOT SIZE vs IN-MEMORY SIZE

  payload (key + value)        : 80 bytes/entry
  snapshot                     : 90.0 bytes/entry (1.13x payload)
  in memory (estimated)        : ~180-200 bytes/entry (2.4x payload)

  The snapshot is far smaller than the live cache because it
  stores only the data. The hash map's buckets and nodes, both
  list pointers, the duplicated key and the allocator's overhead
  all exist to make lookups O(1) -- none of that is worth writing
  down, because loading rebuilds it.

  The in-memory figure is an estimate from the data layout, not
  a measurement -- see ARCHITECTURE.md.
