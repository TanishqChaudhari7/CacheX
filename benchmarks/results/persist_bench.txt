SNAPSHOT SIZE vs IN-MEMORY SIZE

  payload (key + value)        : 80 bytes/entry
  snapshot                     : 90.0 bytes/entry (1.13x payload)
  in memory                    : see MEMORY PER ENTRY in cachex_bench_suite

  The snapshot stores only keys, values and TTLs. The hash map's
  buckets and nodes, the list pointers, the duplicated key and
  allocator overhead exist to make lookups O(1) and are rebuilt
  on load, so none of them is written to disk.
