2. COST OF LRU (identical request sequence, interleaved)
   uniform 50% GET / 50% SET over 100000 keys, 200000 requests, 15 interleaved repeats

configuration                            ops/sec    avg (ns)    evictions
-------------------------------------------------------------------------
unbounded (no LRU)                       8912739       112.2            0
bounded, capacity = key space            8477016       118.0            0
bounded, capacity = 10% of keys          6818366       146.7        80196

  Rows 1 and 2 do identical work; row 2 additionally performs the
  capacity check on every insert. Paired per-repeat comparison over 15 repeats:
    median +0.6%   middle half -0.2% to +6.7%   full range -16.9% to +21.0%
  The interval straddles zero, so the overhead is below this
  harness's noise floor -- the expected result for one predictable
  branch per insert. That is NOT a claim that LRU is free; it means
  this experiment cannot resolve a cost this small.
  (Row 3 is not comparable -- it holds far less data, so its
   memory access pattern differs as well as its work.)
