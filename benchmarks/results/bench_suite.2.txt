MEMORY PER ENTRY (measured, not estimated)
==========================================

entries           heap delta     bytes/entry      vs payload
------------------------------------------------------------
100000                20.6 MiB           216.4           2.70x
250000                52.7 MiB           221.2           2.76x
500000               105.5 MiB           221.2           2.76x

  payload (16-byte key + 64-byte value) = 80 bytes/entry.
  Measured as malloc bytes-in-use before and after building the
  cache, so it covers the two node allocations per entry, the
  value's heap buffer, the duplicated key and the bucket array --
  everything the data structure asks the allocator for. It does
  not include allocator slack within a size class, so the true
  cost to the process is somewhat higher.
